# Consumer Complaint Investigation & Compliance Monitoring

**Portfolio simulation | Regulatory Compliance • Complaint Handling • Root-Cause Analysis • Corrective Actions**

A fictional case-management and compliance-monitoring project designed to demonstrate skills relevant to a **Compliance Analyst — Consumer Disputes and Complaints** position. The dataset contains **30 entirely synthetic consumer complaints** and does not represent any real business, firm, or client.

## What this project demonstrates

- Recording, categorizing and prioritizing incoming consumer complaints
- Assigning response deadlines and monitoring resolution against a **hypothetical** service-level target
- Documenting investigative findings, root causes, corrective actions and resolution statuses
- Analyzing complaint trends and reporting compliance metrics with a formula-driven Excel dashboard
- Identifying recurring issues that merit compliance monitoring, procedure updates or escalation

## How to use

1. Open `complaint_compliance_tracker.xlsx` in Excel.
2. Review **Complaint Register** to see case status, priority, assigned owner, response due date, root cause and corrective action.
3. Open **Dashboard** for calculated totals and counts by complaint category.
4. Read `investigation_sop.md` and `sample_case_report.md` to see the analytical approach and a sample issue escalation.
5. Replace fictional sample values with *new fictional practice cases* as desired. The dashboard formulas cover register rows 2–200.

## Methodology and boundaries

This project uses illustrative **calendar-day** targets of 3 days (high), 5 days (medium) and 7 days (low) to show deadline tracking. These **are not legal requirements, contractual service levels, or Rausch Sturm policies**. Actual complaint-handling deadlines depend on the applicable laws, regulations, contracts, complaint types, and firm policies; a qualified compliance professional must establish them.

**Privacy:** All names, IDs and situations are fabricated. Do not insert real consumer, account, payment, or protected information into this public portfolio.

**Portfolio disclosure:** Self-directed educational simulation, not paid professional compliance work and not an assertion of expertise in any specific consumer-protection law.
